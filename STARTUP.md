# Startup

See detailed startup guide: [scripts/startup/README.md](scripts/startup/README.md)

## Quick Start

**Windows:**
```bash
scripts/startup.bat
```

**Linux/Mac:**
```bash
bash scripts/startup.sh
```

Then open browser to: `http://localhost:8000/deals`

Done. See [scripts/startup/README.md](scripts/startup/README.md) for more.
